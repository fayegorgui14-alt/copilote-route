# Copilote Route

Alerte anticollision sur téléphone : détecte voitures, motos, camions, bus, vélos et piétons devant le véhicule et prévient le conducteur (voix, bip, vibration).

- `index.html` : application des conducteurs (installable sur Android)
- `admin.html` : back-office de l'administrateur
- `fleet.html` : espace entreprise (responsables de flotte)
- `supabase.sql` : base de données (à exécuter une fois dans Supabase)
- `config.js` : adresse et clé publique du projet Supabase

Le copilote aide le conducteur, il ne le remplace pas.
